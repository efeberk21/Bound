# Prior art and reused components

Airlock, Agent Leasebook and Agent Action Warrants are related task-authority ideas. BOUND does not claim to invent expiring agent permission. Its contribution is this narrow implementation of selective Atlas/Boreal revocation, direct logical-executor verification, reusable schema and reproducible evidence.

Reference: https://github.com/Arkiv-Network/arkiv-ideathon/blob/main/SHOWCASE.md

Third-party dependencies: official Arkiv SDK, viem, React/Vite, Zod, Neon serverless driver, iron-session, TypeScript and Vitest. Agent tooling: user-requested Neon skills, installed with `npx neon@latest skills -s neon -s neon-postgres -y`; these are not application runtime features.

UI dependencies added in the 16 October redesign: Motion 14.3.0 and Solar React 2.3.2. Solar artwork is by 480 Design under CC BY 4.0, distributed from its Figma Community set. See `THIRD_PARTY_NOTICES.md`; the icon artwork is not relicensed as BOUND application code.

No code from the user's unrelated projects was imported. This repository began with the provided BOUND planning document; the serverless revision superseded its deployment design. Any final submission's pre-existing-work and coding-assistant declarations must be filled from the actual development record, not invented as “None.”
